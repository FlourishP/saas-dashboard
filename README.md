# SaaS Dashboard

SaaS admin dashboard with analytics charts, user management, billing, and role-based access.

## Features
- Revenue analytics with interactive charts
- User management & roles
- Billing & subscription management
- Activity logs
- Real-time notifications

## Tech Stack
Next.js 14, TypeScript, Recharts, NextAuth, Tailwind CSS

## Getting Started
```bash
npm install
npm run dev
```
